# License and attribution records

No repository-wide license has been selected for this project. Do not add a license declaration
or treat the absence of one as permission to reuse source material.

Before source files or assets are migrated, review rights and applicable terms. For each
third-party source or asset, record at least:

- upstream project, URL, pinned commit or release, and the exact copied paths;
- authors/copyright holder, license name, and license URL or included license text;
- required attribution/citation, redistribution or non-commercial restrictions, and any
  notices that must accompany the material;
- modifications made during migration.

Preserve required notices and license texts with the files they cover. The pinned
`town_model` source has no top-level license file, so its code's reuse terms must not be
inferred from the separate license declared by upstream Pizzaïolo. Escalate unclear rights
before copying; record the resolution here or in a linked asset-specific notice.
